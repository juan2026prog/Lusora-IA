# Lusora IA

Plataforma mobile-first de experiencias simbólicas interactivas impulsadas por IA.

## Fase actual
Experiencia visual y sensorial antes de infraestructura comercial.

## Stack inicial
- Next.js + TypeScript
- Tailwind CSS
- Framer Motion

## Ejecutar
```bash
npm install
npm run dev
```

## Principio de producto
Primero validamos que la experiencia se sienta especial en un teléfono. Backend, cuentas, monetización y Site OS se integrarán después.
